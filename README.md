A one-line voicemail greeting recorded by a cat: Biscuit knocked the phone off the table, so this is your voicemail now — leave a message and he'll sit on it. Entry for make.fun's "Funniest Cat Voicemail Greeting" bounty, judged pairwise by an AI comedy judge.

## Run it

```sh
python3 main.py
```

The program writes the greeting (118 characters) to `/output/entry.txt`.
